Dusk Harbor — a tactical three.js FPS set in a working port at sunset. Two bomb sites (a container yard and a warehouse), three lanes, 5v5 rounds with a buy economy: four weapons, an HE grenade, and armor. Plant the bomb, hold the site, or defuse it. Bots patrol lanes, hold positions, rotate to gunfire and to a planted bomb, and react with human-ish delay. Fixed-step 60 Hz simulation, deterministic screenshot mode, synthesized WebAudio sound, no external assets.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
